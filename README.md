# Car Maintenance Tracker
## Project Objective
This project aims to create a web application that allows the user to keep track of car maintenance actions in an organized and consistent manner.
## Key features
* Uses Tabulator for easy table management
* Color coded maintenance status for easy recognition
* Saves/loads to the users local drive
## How to use
1. Add table rows with the maintenance action names and mileage durations
2. Use the entry field at the top and the update bottoms to initialize the start mileage for each action
3. When checking the maintenance statuses, enter the current mileage and press check
